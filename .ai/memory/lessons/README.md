# Lessons Memory

Store concise, reusable lessons that can improve future implementation, debugging, testing, review, delivery, or maintenance.

## Store Here

- Verified failure patterns.
- Effective diagnostic techniques.
- Non-obvious repository behavior.
- Reusable implementation or validation guidance.
- Conditions where the lesson applies or does not apply.
- Links to supporting tasks, incidents, tests, code, or documentation.

## Do Not Store

- General programming knowledge.
- Temporary notes or unresolved speculation.
- Large logs, transcripts, or duplicated documentation.
- One-time facts that are easy to rediscover.
- Secrets or sensitive data.

## Naming

Use a stable name such as `YYYY-MM-DD-short-lesson-title.md`.

## Template

Use `/templates/lesson-template.md`.

## Maintenance

Update or supersede a lesson when later evidence changes its applicability.
