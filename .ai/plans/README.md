# Plans

Implementation plans for work that is complex, risky, cross-cutting, or expected to span multiple sessions.

## Lifecycle

- `active/`: approved plans currently in use.
- `completed/`: plans whose work has been completed and validated.
- `abandoned/`: plans intentionally stopped or replaced, with the reason recorded.

## Requirements

A plan should define objective, scope, assumptions, affected components, ordered steps, validation, risks, rollback, documentation impact, and completion criteria.

Do not create plans for trivial isolated changes unless explicitly requested.
