# Task Templates

Templates for creating tracked work items.

## Files

- `task-template.md`: use for features, chores, investigations, documentation changes, and general implementation work.
- `bug-template.md`: use for defects with observed behavior, expected behavior, reproduction, suspected impact, and regression validation.

## Rules

- Create work in `.ai/tasks/inbox/` until it is clear enough to execute.
- Move work to `.ai/tasks/active/` only when the objective, scope, acceptance criteria, and validation plan are actionable.
- Move work to `.ai/tasks/completed/` only after completion evidence is recorded.
