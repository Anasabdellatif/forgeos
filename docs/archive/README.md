# Documentation Archive

This folder stores historical documents that are no longer active sources of truth but may be useful for traceability.

## Store Here

- Superseded requirements, architecture notes, or design drafts.
- Historical planning material that should not guide current implementation.
- Deprecated operational procedures kept for audit context.

## Do Not Store

- Current product, architecture, domain, design, or operations guidance.
- Secrets, credentials, personal data, or raw sensitive logs.
- Large generated artifacts unless explicitly required for audit.

## Rules

- Mark archived documents with the date archived and the active replacement when one exists.
- Do not allow archived documents to override current sources of truth.
- Prefer concise summaries and links over duplicated long documents.
